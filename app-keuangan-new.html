Langkah setup (sekali saja):

1. Buka script.google.com → Proyek baru
2. Hapus kode awal, paste kode dari file hermon-gsheets-backend.gs
3. Klik Deploy → New Deployment
4. Pilih tipe: Web App
5. Execute as: Me
6. Who has access: Anyone
7. Klik Deploy → salin URL yang muncul
8. Paste URL di tab Setup di atas → Test → Simpan
