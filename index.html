Cara Menghubungkan Google Spreadsheet
📋 Metode 1: Google Apps Script (Direkomendasikan)
  1. Buka Google Spreadsheet baru, buat 10 sheet bernama: Utama, Maranatha, Berkat, Imanuel, Sion, Yordan, Lahir, Wafat, Atestasi Masuk, Atestasi Keluar
  2. Di Spreadsheet, klik Extensions → Apps Script
  3. Tempelkan kode GAS dari tombol di bawah
  4. Klik Deploy → New Deployment → Web App
  5. Set "Who has access" ke Anyone, klik Deploy
  6. Copy URL Web App dan tempelkan di kolom "Web App URL" di tab Konfigurasi
🔑 Metode 2: Service Account API
  1. Buka console.cloud.google.com, aktifkan Google Sheets API
  2. Buat Service Account, unduh file JSON credentials
  3. Share spreadsheet ke email Service Account
  4. Tempelkan isi JSON di kolom "Service Account JSON"
